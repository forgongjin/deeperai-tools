FAQ

Q: Do my files get uploaded?
No. Everything runs locally in your browser. The page itself is static — there's no backend to upload to.

Q: Why is it free?
Core features are free forever. Advanced features (batch limits, larger files) are available via Pro (one-time purchase through Lemonsqueezy).

Q: Large file support?
Free tier: up to 10MB per file. Pro: up to 50MB. PDF processing is limited by browser memory — very large files work better with desktop software.
