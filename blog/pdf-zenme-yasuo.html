方法二：Adobe Acrobat 在线压缩

效果好，但要上传文件。免费版每天有限额（2 次/天），用完要等。适合不敏感的普通文档。

⚠️ 注意：上传到 Adobe 服务器，处理完他们承诺删除文件，但过程本身有传输风险。如果是私密文档，不推荐。

方法三：Smallpdf

同 Adobe 类似，免费版每天 2 个任务。画质保持不错，但隐私方面同样要打个问号——文件要上传。

方法四：国产 PDF 软件

WPS、福昕、迅捷等。压缩效果参差不齐，有些会把图片压得全是马赛克。最要命的是广告弹窗和捆绑安装。

方法五：Mac 预览 / Windows 打印到 PDF

系统自带，纯本地操作。Mac 预览 → 导出 → Quartz 滤镜选 Reduce File Size；Windows 用打印到 PDF。优点是安全免费，缺点是压缩率低（15%-30%），很多时候不够用。

为什么 PDF 文件会这么大？

PDF 体积大通常有几个原因：

  • 高清图片：PPT 或 Word 导出时图片没压缩，原图分辨率直接嵌进去了
  • 扫描件：扫描仪默认 300-600dpi，没做任何优化
  • 字体嵌入：整包字体嵌入 PDF，一个中文字体包可能就好几 MB
  • 多余元数据：修改记录、注释、书签等

压缩工具做的事情：缩小嵌入图片的分辨率、移除冗余数据、优化字体子集。

PDF 压缩常见问题

压缩后文字看不清了？

大概率是压缩强度太高了。降低一档试试。如果是扫描件，建议用「中」或「低」强度。

免费版有文件大小限制吗？

PDF轻处理免费版支持最多 10MB/文件的压缩。更大的文件可以先用拆分功能分成小份再压缩。

压缩后页码会变吗？

不会。压缩只影响嵌入的图片质量和文件结构，不改变页面内容和数量。
